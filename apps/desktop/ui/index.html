Mantel Calendar

This window shows the calendar from your Mantel server. It starts at this PC. Point it at a Raspberry Pi later by changing the address.

On this PC that is http://localhost:8080. A bare address such as 10.0.15.178 is tried on port 8080. If the server is not on a trusted network, the calendar asks for the pairing code from the wall: Settings → Devices → Pair a phone.
