# Mantel on an iPhone

A native SwiftUI companion for the wall calendar. Build and install notes, pairing, and the feature list are in [apps/ios/README.md](../apps/ios/README.md).

The app talks to the same API as the [Android phone app](android-phone.md). Pairing uses the scheme in [authentication.md](authentication.md). Reach the server on the LAN or over WireGuard; do not port-forward it.
